# คู่มือการติดตั้งระบบผลการเรียนบน HostAtom (PHP + MySQL)
โรงเรียนมกุฎเมืองราชวิทยาลัย

---

## 📁 รายการไฟล์สำหรับนำขึ้น HostAtom

| ชื่อไฟล์ | คำอธิบาย |
| :--- | :--- |
| **database.sql** | ไฟล์โครงสร้างตารางฐานข้อมูล MySQL สำหรับ Import ใน phpMyAdmin |
| **config.php** | ไฟล์ตั้งค่าเชื่อมต่อฐานข้อมูล (Database Name, User, Password) |
| **api.php** | Backend API สำหรับบันทึก/ดึงคะแนนและประมวลผลผลการเรียน |
| **index.php** | หน้าเว็บหลัก UI พร้อมฟังก์ชันรายงานและพิมพ์ผลการเรียน |

---

## 🚀 ขั้นตอนการติดตั้งบน HostAtom (5 ขั้นตอน)

### ขั้นตอนที่ 1: สร้างฐานข้อมูล MySQL บน HostAtom
1. เข้าสู่ระบบ Control Panel (cPanel หรือ DirectAdmin) ของ HostAtom
2. ไปที่เมนู **MySQL Databases (ฐานข้อมูล MySQL)**
3. สร้างฐานข้อมูลใหม่ เช่น: `mmv_grade_db`
4. สร้างผู้ใช้ฐานข้อมูล (Database User) พร้อมรหัสผ่าน เช่น User: `mmv_user` และรหัสผ่าน
5. ในส่วน **Add User To Database** ให้เลือก User และ Database ที่เพิ่งสร้าง แล้วกด **Add** พร้อมติ๊กถูก **ALL PRIVILEGES** เพื่อให้สิทธิ์เต็ม

---

### ขั้นตอนที่ 2: นำเข้าตารางฐานข้อมูล (Import database.sql)
1. ใน Control Panel เข้าเมนู **phpMyAdmin**
2. คลิกเลือกชื่อฐานข้อมูลที่สร้างไว้ที่เมนูด้านซ้าย
3. คลิกแท็บ **Import (นำเข้า)** ที่แถบเมนูด้านบน
4. กดปุ่ม **Choose File (เลือกไฟล์)** แล้วเลือกไฟล์ **`database.sql`**
5. เลื่อนลงมากดปุ่ม **Import (เริ่ม/นำเข้า)** ที่ด้านล่างสุด
*(ระบบจะสร้างตาราง 7 ตารางพร้อมข้อมูลเริ่มต้นให้ทันที)*

---

### ขั้นตอนที่ 3: แก้ไขไฟล์ config.php
เปิดไฟล์ **`config.php`** แล้วแก้ไขข้อมูลเชื่อมต่อให้ตรงกับที่สร้างไว้ในขั้นตอนที่ 1:

```php
define("DB_HOST", "localhost");
define("DB_NAME", "ชื่อฐานข้อมูลของคุณ");   // เช่น u1234567_mmv_db
define("DB_USER", "ชื่อผู้ใช้ฐานข้อมูล");   // เช่น u1234567_mmv_user
define("DB_PASS", "รหัสผ่านฐานข้อมูล");     // รหัสผ่านที่ตั้งไว้
```

---

### ขั้นตอนที่ 4: อัปโหลดไฟล์ขึ้น HostAtom
1. ใน Control Panel เข้าเมนู **File Manager (ตัวจัดการไฟล์)**
2. ดับเบิ้ลคลิกเข้าไปที่โฟลเดอร์ **`public_html`**
3. กดปุ่ม **Upload** แล้วอัปโหลดทั้ง 3 ไฟล์ขึ้นไป:
   - `config.php`
   - `api.php`
   - `index.php`

---

### ขั้นตอนที่ 5: เริ่มต้นใช้งานระบบ
1. เปิดเว็บเบราว์เซอร์แล้วเข้าชื่อโดเมนของคุณ เช่น `https://www.yourdomain.com`
2. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบเริ่มต้น:
   - **Username:** `admin`
   - **Password:** `1234`
3. ไปที่แท็บ **"จัดการฐานข้อมูล"** เพื่อนำเข้าข้อมูลครู และภาระงานสอนด้วยไฟล์ Excel หรือฟอร์มได้ทันทีครับ!
